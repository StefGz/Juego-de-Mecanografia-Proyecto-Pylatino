<h1>⌨️ Juego de Mecanografía</h1>

<h3>🎯 Sobre el Proyecto</h3>

Este es el proyecto final para el curso de Python de Pylatino. Es un juego de mecanografía simple que se ejecuta en la consola, diseñado para probar la habilidad de escritura en el teclado.

La principal característica es que las frases del juego son generadas en tiempo real por un modelo de Inteligencia Artificial (GPT).

<h3>✨ Características Principales</h3>

<ul>
  <li><b>Dificultad Personalizada:</b> Puedes elegir entre 4 niveles que controlan la complejidad de las frases generadas por la IA.</li>
  <li><b>Libertad de temas:</b> El usuario ingresa sus propios temas (ej. "ciencia", "arte"), y la IA genera el contenido basado en ellos.</li>
  <li><b>Modo Competición:</b> Utiliza un sistema de vidas (3 o 5, según la dificultad) y cuenta las rondas superadas como puntuación.</li>
  <li><b>Desafíos:</b> 🎲 Incluye un 20% de probabilidad de que las frases aparezcan en orden inverso, añadiendo un desafío inesperado de atención.</li>
</ul>

<h3>🛠️ Requisitos e Instalación</h3>

Este proyecto fue desarrollado en Python y se juega enteramente en la consola.

<h4>Dependencias</h4>

El juego requiere las siguientes librerías:

<ul>
<li>time y random (librerías estándar de Python).</li>
<li>El módulo ai (suministrado por Pylatino), que gestiona la conexión a la API de GPT.</li>
</ul>
